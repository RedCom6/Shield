# Щит для Android — браузер с блокировкой рекламы

## Способ 1: Android Studio (на компьютере)
1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Подключите телефон (отладка по USB) и нажмите Run, либо Build → Build APK.

## Способ 2: без компьютера и без установки Android Studio (GitHub)
1. Создайте репозиторий на github.com и загрузите в него все файлы проекта
   (включая папку .github).
2. Откройте вкладку Actions → Build APK → Run workflow.
3. Через пару минут скачайте артефакт shield-apk, распакуйте и установите app-debug.apk
   (разрешите установку из неизвестных источников).

## Возможности
Вкладки, поиск Google, блокировка рекламных доменов (счётчик 🛡),
блокировка всплывающих окон, скрытие пустых рекламных блоков.

Реклама внутри видео (например, YouTube) этим способом не блокируется.
Свои домены добавляйте в adDomains в MainActivity.kt.
